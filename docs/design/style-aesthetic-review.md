# 多风格 UI 审美专项评审报告

> 评审对象：同一套个人网站内容（首页）的 20 种 UI 大风格实现 + 风格画廊页
> 素材：`.shots/` 下 41 张真实渲染截图（每风格桌面 1440×2400 + 移动端，另含画廊页）
> 评审基准：`6种主流UI大风格.md`、`其他15种UI大风格.md` 的权威定义 + `styles/registry.ts` 的 tier 与定位
> 评审方法：以桌面图为主、移动图为辅，逐张读图后按五维度打分（10 分制）
> 声明：桌面图为 reduced-motion 模式渲染，内容完整可信；移动端截图受截图工具视口钳制（约 500px 布局裁右），**右缘截断不计缺陷**；hover 等交互态不在评审范围。pixel 与 terminal 截图最底部的浅色横纹条带疑似截图工具产物，不计缺陷。

---

## 一、总览

这套多风格实现的整体水准**显著高于同类"皮肤站"的平均线**：20 种风格里没有一个是"换个颜色值交差"的，绝大多数都做到了定义中"不是换值、是换性质"的要求——pixel 关掉圆角换成点阵字体和游戏 HUD 隐喻、retro-computer 用凹凸斜面和任务栏重构整个窗口隐喻、skeuomorphism 用纯 CSS 拼出皮革/木纹/纸张/黄铜四种材质、swiss 把强调色压到红黑白三色并把网格线本身做成装饰。横向看，暗色系（cyberpunk / sci-fi-hud / terminal）彼此差异化做得好，青粉霓虹、绿琥珀军用、纯绿单色三条路线互不串味。

主要短板集中在三处：其一，**"精选项目"单卡 + 大片空腔**是 cyberpunk、sci-fi-hud、flat-design 三个风格的共同病灶，单条内容撑不起全宽面板；其二，个别风格存在**大面积死空间或近不可见的 CTA**（neumorphism 首屏下方约 300px 死灰区、y2k 首屏按钮几乎隐形），属于气质级问题；其三，**画廊页是全站最不"风格化"的页面**——卖 20 种视觉风格的页面自己却是 20 张一模一样的灰白卡片。

## 二、逐风格评审

### 1. Neo-Brutalism 新粗野主义 —— 9.3 S

**截图观察**：米白底上，巨型黑体标题 SINCLAIR-CXP 带黄色错位投影，右缘压着一个旋转的黑白斜纹方块贴纸；"你好，我是"做成黑底白字贴纸标签；三枚按钮（黄/白/蓝）全部粗黑描边 + 硬阴影；黑色跑马灯横幅微微旋转、重复文案间嵌黄色五角星；关于我黄色大卡片配 ○■▲ 几何符号，技能黑面板里黄/蓝/白三色标签高饱和撞色；工作经历四张卡片左右交错（第 1 张偏左、第 2 张偏右、第 3 张居中偏左、第 4 张偏右），白黄交替、全部硬投影；区块标题全部做成黑色贴纸（工作经历/精选项目），辅以超粗黑色分隔线。

**亮点**：
- 硬阴影 + 粗描边 + 撞色的组合执行力极高，"贴满海报的工作台"气质一眼成立；
- 跑马灯横幅微旋转 + 五角星分隔，是标准的 brutalist 海报手法且与内容（职位的自我介绍）绑定；
- 时间线卡片左右交错打破文档感，尺寸对比也做进来了（首屏标题与正文的字号悬殊极大）。

**问题**：
- P2：首屏按钮组（约 y=560）与第一条粗分隔线（约 y=770）之间约 200px 只有一个右下角小箭头，中景偏空，海报的"密"没有延续下来；
- P2：技能黑面板内三色标签（黄/蓝/白）分配看似随机，撞色有了但缺一点"故意的规律"；
- P3：斜纹方块与标题的 P 字有轻微交叠，拼贴感成立，但方块旋转角度再大一点会更"贴上去"。

**建议**：中景空档可加入一张旋转 2-3° 的纯色/斜纹海报块（如"15+ 技能""8 年经验"数据贴纸）压住重心；技能标签按"前端=黄、后端=蓝、工具=白"定规律；斜纹方块旋转至 -6° 左右并让标题投影压在其上，拼贴层次会更强。

### 2. Skeuomorphism 拟物主义 —— 9.1 S

**截图观察**：深色木纹墙面背景上钉着一块带虚线缝线 + 四角黄铜铆钉的棕色皮革主板，金色衬线大标题；两枚皮质按钮（深皮金边、黄铜面）；工作经历是铆钉皮革大板内嵌四张小皮卡，年份全部做成金色金属铭牌；技能列四张皮卡居中缀金色挂环，技术栈做成钉在皮革上的白色纸质标签；精选项目是一张奶油色横线便签纸，红色装订线、顶端红色图钉、右上角红色"精选"圆形图钉徽章；页首皮革导航条带高光。

**亮点**：
- 皮革、木纹、纸张、黄铜四种材质在同一页面分工明确（容器=皮革、背景=木、内容=纸、点缀=黄铜），这是教科书级的材质系统；
- 缝线、铆钉、挂环、图钉、装订线五组"物理构件"全部服务于内容组织，不是纯装饰；
- 金色衬线 + 纸质白标签的对比让信息层级在低明度背景上依然清晰。

**问题**：
- P2：皮革卡内灰色描述文字（如"核心前端架构设计与开发……"）对比度偏低，暗棕底上接近可读性下限；
- P3：技能白色纸签在整版深棕中出现四簇，明度跳跃略突兀，可把纸签加一点点暖色（米黄）过渡；
- P3：英雄皮板上下留白偏大，内容集中在垂直中线，皮革面积利用率略低。

**建议**：描述文字提高一档明度（或改米金色）；纸签统一换米黄纸色并加深一点投影；英雄皮板内可加一枚皮革压印 logo 或黄铜铭牌填充上部空间。

### 3. Retro-Computer 复古电脑 —— 9.1 S

**截图观察**：经典 Win95 青绿桌面上，顶部一条灰色任务栏（含嵌入式时钟 04:55）；"Sinclair-CXP · 首页"蓝色渐变标题栏 + 最小化/最大化/关闭三键；窗口内容银灰底带半调网点纹理，竖排蓝色强调条；查看博客/查看项目是标准凸起斜面按钮；技能四组做成**下凹输入框**（把技术栈塞进 text field 里，是很聪明的拟物转译）；精选项目窗口内有文件夹图标的树状视图；最新文章窗口每条带文档图标 + 凸起小按钮标签；底部任务栏有"回到精选"开始按钮 + 五个窗口按钮；桌面右下留出大面积青绿"桌面"。

**亮点**：
- 凹凸斜面（bevel）运用系统化：按钮凸、输入框凹、任务栏槽线、窗口分组线，方向语义全对；
- "技能 = 表单输入框"的转译是全站最聪明的单点设计，把 90 年代表单隐喻用活了；
- 树状视图（📁 个人网站项目）+ 文档图标列表，窗口内的信息组织完全按老系统的心智模型来。

**问题**：
- P2：半调纹理银灰底上的灰色描述文字对比度偏低（比主站正文明显吃力）；
- P3：右下桌面空区较大，虽有"这是桌面"的隐喻兜底，但缺一个桌面图标（如"我的电脑/回收站"式的入口）呼应；
- P3：两个窗口列的高度差较大（左侧关于我/最新文章很长，右侧精选项目/联系我很短），桌面下缘参差。

**建议**：描述文字提到 #333 一档；右下桌面加一两个桌面图标（可指向画廊或 GitHub）；右侧窗口可与左列底对齐或在窗口内补一条状态栏填充。

### 4. Pixel 像素风 —— 9.0 S

**截图观察**：深藏青底 + 细像素网格；顶部绿色等宽导航（▸ 前缀）+ 绿色进入风格按钮；英雄面板白色双线像素边框内含太空侵略者像素精灵徽章 + 白色点阵标题；ABOUT 关于面板内四条时间线，年份全部做成绿色描边像素框；**STATUS 技能（窄，约 40%）与 INVENTORY 精选项目（宽，约 55%）双栏宽度比约 5:7 形成尺寸悬殊**——技能做成 RPG 状态栏（前端 8/8 满格绿块、后端 3/8、DevOps 2/8、工具 2/8），精选项目做成物品栏（01 号槽位高亮边框 + 道具名 + 绿色元信息 + 两枚操作按钮）；QUEST LOG 文章列表行内左日期右绿色职业徽章；CONTACT 四行黄色标签 + 像素化二维码 + "复制微信号"按钮。

**亮点**：
- "不是换值、是换性质"的标杆：无圆角、无过渡、有限色板（藏青/白/绿/黄），整套 UI 语言重写为游戏菜单；
- STATUS/INVENTORY 的隐喻不是贴皮——技能熟练度用血条格数表达（8/8、3/8 可读出相对水平），精选项目用"选中物品槽"表达，信息与隐喻互证；
- QUEST LOG / CONTACT 的行式布局与徽章系统保持像素纪律，中文回退字体与点阵英文混排也稳。

**问题**：
- P2：ABOUT 面板四条时间线卡片等宽等距同形态，是全页最"列表文档"的一段，与其他面板的游戏隐喻密度有落差；
- P3：正文中文小号灰字在深底上略闷（点阵英文字体管不到中文，字号也偏小）；
- P3：底部页脚区域（浅色横纹条带若非截图伪影）与整体像素语言衔接不明。

**建议**：ABOUT 面板可把四条时间线改为"任务日志"行式（年份徽章 + 任务名 + 完成度格子），与 QUEST LOG 呼应；正文中文提高一档明度或字号；页脚若保留，做成一条"GAME OVER / SAVE POINT"式的像素状态条收尾。

### 5. Swiss 瑞士国际主义 —— 9.0 S

**截图观察**：白底上隐约可见的竖向网格线（12 列感）；顶部红色细条 + 表格式导航（SINCLAIR-CXP | 01 关于 | 02 项目集锦 | 03 博客 | 04 联系 | ↗ 画廊），单元格竖线分隔；全宽 Helvetica 风黑色大标题；红方块 + "你好，我是"；左列两行"查看博客 ↓ / 查看项目 ↓"（红色箭头），右列副标题 + 说明，非对称双栏；01 关于我特粗黑标题 + 右对齐小注；技能/工作经历全部是带编号（红色 01-04）的行式表格 + 发丝线分隔；02 精选项目粗黑规则线 + 日期右对齐。

**亮点**：
- 黑白 + 单一红的色彩纪律执行到 icon 级（红只出现在编号、方块、箭头、顶条四处）；
- 发丝线表格 + 编号系统让"信息即装饰"，无一处多余图形；
- 非对称双栏（左链接列 / 右文案列）+ 右对齐注释，网格纪律下的张力做出来了。

**问题**：
- P3：背景网格线太淡（几乎不可见），瑞士风"把骨架亮出来"的签名打了折扣；
- P3：首屏大标题为黑白灰三色中的黑，缺一个红色几何锚点（经典瑞士海报常用一个红圆/红块压角）；
- P3：精选项目单条信息量小，右半区空。

**建议**：网格线透明度提高约一倍（仍保持克制）；首屏右侧空白处落一枚大号红色几何形（圆或 45° 方块）与标题形成对位；精选项目条目可加技术栈灰字行填充右区。

### 6. Claymorphism 黏土拟态 —— 8.9 A

**截图观察**：淡紫粉渐变天空 + 漂浮的立体光泽黏土球（粉/橙/黄/蓝/绿/紫）；白色胶囊导航 + 紫色球 logo + 粉色画廊按钮；英雄区紫色胶囊徽章、超大白色药丸容器包住深紫粗体标题、紫/绿两枚厚底双影按钮；**英雄区底部用一朵白色云朵波形（两个凸包）过渡到内容区**；01 关于我淡紫大板内四条时间线卡片按紫/绿/黄/粉轮换色、年份胶囊徽章、虚线时间轴 + 圆珠节点；02 技能薄荷绿大板内四张白色子卡，各带计数徽章 + 淡紫进度槽 + Pastel 胶囊标签。

**亮点**：
- 云朵波形分界是"黏土世界"的场景级叙事，比任何阴影都更能传达"捏出来的"；
- 厚重卡片的"双层影"（大范围柔影 + 底部收紧）+ 胶囊徽章 + 圆珠节点，黏土的物理感成体系；
- Pastel 轮换色（紫/绿/黄/粉）时间线让长内容有节奏，不靠边框靠色相。

**问题**：
- P3：Pastel 色相数偏多（单屏同时出现六种），离"彩虹化"仅一步之遥，收敛到三主色 + 一个点缀会更高级；
- P3：技能白色子卡内进度槽颜色与标签色不完全对应（前端槽是淡紫、标签也是淡紫，但 DevOps 槽淡粉、标签也淡粉，规律成立；唯独后端槽与标签同为绿但板底也是绿，层次略平）；
- P3：英雄标题药丸容器宽度固定，两侧大量渐变空白，气球散点分布略随机。

**建议**：将漂浮球收敛为紫/粉/黄三色系；后端子卡改白色底或槽色加深，避免与板底同色；药丸容器可改为自适应内容宽 + 一枚黏土星形贴纸打破对称。

### 7. Minimalism 极简主义 —— 8.9 A

**截图观察**：暖白底；顶栏仅 logo + 四链接 + 描边按钮；首屏极细体大标题 + 灰阶两级副文案 + 两条下划线文字链接（查看博客/查看项目）；一条居中细竖线分隔首屏与内容；右缘一枚大圆细线 + 小圆点装饰；关于区左标题右内容的不对称双栏；技能做成分组定义列表（组名小字 + 一行灰点分隔的技术名），工作经历做成年份左置的行式条目，全部发丝线分隔；精选项目为日期 + 标题箭头 + 点分隔标签 + 文字链接。

**亮点**：
- 全页仅黑白灰 + 一枚蓝点，下划线文字链接替代按钮，克制到 icon 都没有——这正是"让每个元素都经过取舍"的定义执行；
- 发丝线 + 点分隔符（·）+ 右对齐年份构成三套极轻的秩序工具，信息密度不低却不显拥挤；
- 竖线分隔 + 大圆细线证明"极简也有构图"，不是单纯留白。

**问题**：
- P2：技能一行内英文断词——"EC"harts 被折成"EC / harts"（移动端同样断在 EC 处），中英混排未做 keep-all，是全页唯一的排版硬伤；
- P3：关于区左栏在标题以下整段空置（右侧内容延伸约 700px），左下死区略大；
- P3：目录/关于两个区块间距（约 270px）虽是留白语言，但与区块内部行距的比例关系偏松。

**建议**：为技术栈列表加 `word-break: keep-all`（或把英文词组包在 `white-space: nowrap` 的 span 中）；左栏标题下补一行灰色 meta（如"更新于 2026-09"）或将标题改为 sticky 跟随；区块间距按 1.5 倍内部行距重新校准。

### 8. Editorial 杂志编辑排版 —— 8.9 A

**建议**：描述文字提亮一档；短卡片可降低高度（自适应）或补一行 mono 小字说明填充；副按钮加浅描边或提亮底色。

### 18. Glassmorphism 玻璃拟态 —— 8.1 A

**截图观察**：青→薰衣草→粉的极光渐变底 + 数枚大直径柔光圆斑；磨砂白胶囊导航；渐变（蓝→紫）巨标题 + 紫粉渐变主按钮 + 白玻璃副按钮；右侧漂浮三枚白玻璃统计小卡（14 博客 / 1 项目集锦 / 15 技能）；关于我为**巨型磨砂玻璃卡内嵌多块子玻璃卡**（技能四组 + 时间线四条，子卡各有白色半透底 + 细白描边），时间线年份为紫色玻璃胶囊、节点为空心圆环；精选项目同为玻璃大卡 + 项目子卡（等宽技术栈文字 + 双链接）。

**亮点**：
- 多层玻璃（大卡套子卡）+ 白色细描边 + 极光底穿透，"磨砂玻璃放彩色背景上"的定义还原准确；
- 漂浮统计小卡把数据做成玻璃装饰，背景圆斑恰好从卡后透出，blur 有物可磨；
- 紫色系强调（年份胶囊、渐变标题）在粉青底上锚定了视觉重心。

**问题**：
- P2：巨型关于我卡的玻璃透明度偏低（接近实白），"透"的快感让位于"白"的存在感，与子卡层次反而拉不开；
- P3：技能"工具"子卡仅两枚标签却与其他组等高，玻璃卡内空置明显；
- P3：精选项目子卡内技术栈为纯文字（绿灰色 mono），与全页胶囊标签语言不一致。

**建议**：大卡透明度下调（更透），子卡透明度上调（更白），拉大两层层级；子卡高度自适应；项目技术栈改为与技能区一致的小胶囊。

### 19. Neumorphism 新拟态 —— 7.9 B

**截图观察**：通体同一浅灰蓝底；凸起胶囊导航 + 凸起圆形 SC 头像徽章；粗体深灰标题 + 蓝色文字链 + 两枚凸起胶囊按钮；**首屏按钮（约 y=480）到关于我卡片（约 y=790）之间约 300px 纯粹的空灰底**；关于我凸起大卡：时间线蓝色凸起圆点 + 右侧凸起年份胶囊；技能卡：内凹槽 + 蓝色凸起填充的进度条（凸凹对用得最准的一处）+ 凸起标签胶囊；精选项目凸起卡。

**亮点**：
- "从一块材料里压出来"的核心语法成立：全页零边框、零色差，形体全靠双光源双向阴影；
- 进度条的凹槽 + 凸起填充是 neumorphism 语义最顺的构件；
- 凸起年份胶囊、圆点等小构件尺寸统一，阴影角度一致（左上光）。

**问题**：
- P1：**首屏与内容区之间约 300px 的死灰区**——无发丝线、无装饰、无内容，在均质底色上读作"页面断了"而非"留白"；
- P2：全页仅靠阴影造型，灰底 + 灰卡的明度几乎无差，信息区块的边界感弱（尤其滚动时）；
- P3：英雄区只有标题 + 两按钮，缺一件"凸起物"展示材质（如拟物开关/旋钮）。

**建议**：死区压缩一半并加入一组新拟态招牌构件（凸起表盘、内凹搜索槽或音量推子）作为首屏装饰兼签名；卡片底色与页面底色拉开 2-3% 明度，或给卡片加 1px 同色高光描边增强轮廓；首屏加一枚交互暗示构件。

### 20. Liquid-Glass 液态玻璃 —— 7.5 B

**截图观察**：深紫夜色底；悬浮胶囊玻璃导航（含青色"进入风格"按钮）；英雄为一块大圆角半透明玻璃板，内含青色小字 + 蓝紫渐变巨标题 + 玻璃胶囊双按钮 + 右下小圆钮；板外左缘、右上方各一枚深色圆形玻璃泡；关于我为全宽玻璃大板：左侧时间线（玻璃圆珠节点 + 青色年份），右侧技能四组玻璃容器内胶囊标签；项目玻璃卡 + 玻璃胶囊标签；区块右上角小圆形序号（1/5）。

**亮点**：
- 玻璃层叠的结构成立（导航浮层、英雄板、内容板、标签容器四层透明度阶梯）；
- 青色小标签 + 渐变标题构成"高端消费电子"的冷静气质；
- 圆角半径系统一致（板大圆角、胶囊全圆），层次靠透明度而非描边。

**问题**：
- P1（就定义而言）：**"折射与背景模糊"几乎是缺席的**——背景近乎纯色深紫，玻璃板后面没有可被模糊/透射的内容，材质退化为"半透明深色卡片"；与 glassmorphism（有极光 + 圆斑穿透）对比后差距明显；
- P2：玻璃泡、序号圆等装饰与内容无互作（不透出、不折射），漂浮感靠位置不靠光学；
- P3：英雄板内右侧约 45% 宽度空置（渐变标题只占左半）。

**建议**：在玻璃板后方布设彩色光斑/渐变球（让 backdrop-filter 有内容可 blur），并在板缘加 1px 亮边 + 内侧高光模拟玻璃折边；英雄板右侧放一枚大号玻璃球体或折射感数字（如"08"年经验）填补；两风格（liquid-glass 与 glassmorphism）应从"暗色玻璃/亮色玻璃"继续拉开材质差异。

## 三、横向发现

### 最出彩的 3 个

1. **Neo-Brutalism（9.3 S）**：从跑马灯、贴纸标题、错位时间线到撞色标签系统，整套语言没有一处"温和化"的妥协，是 20 个风格里气质最完整、最敢做的实现。
2. **Skeuomorphism（9.1 S）**：皮革/木纹/纸张/黄铜四材质各司其职，缝线、铆钉、图钉、装订线等物理构件全部参与信息组织，纯 CSS 做到了"能骗过第一眼"的材质错觉。
3. **Retro-Computer（9.1 S）**：Win95 隐喻贯穿到任务栏、时钟、树视图与表单输入框，尤其"技能 = 下凹输入框"这种把内容塞进隐喻构件的转译，是全站聪明度最高的单点设计。

（Pixel 与 Swiss 同列 S 级，前者胜在隐喻系统（STATUS/INVENTORY/QUEST LOG），后者胜在色彩纪律，与上述三者共同构成第一梯队。）

### 相对偏弱的 3 个及原因

1. **Liquid-Glass（7.5 B）**：玻璃风格的前提是"背后有东西可透"，当前深紫纯色背景让 backdrop-filter 无米下锅，材质签名塌掉一半——这是 20 风格里唯一"性质没换够"的实现。
2. **Neumorphism（7.9 B）**：语法正确但页面经营不足：300px 死灰区 + 全页明度无差，新拟态本就依赖"物件感"，没有物件时它比任何风格都显空。
3. **Y2K（8.4 A，问题最尖锐的一个）**：意象组合（铬标题、全息 CD、气泡标签）质量很高，但首屏 CTA 几乎不可见属于功能性失误，拉低了整个A 级的完成度口碑。

### 跨风格共性问题

- **"精选项目单卡 + 空腔"三连**：cyberpunk、sci-fi-hud、flat-design 的精选项目区都是一张卡居左、右侧/下方大片空置（内容只有 1 条是客观原因，但版式未做应对）；
- **暗色系描述文字对比度普遍贴线**：cyberpunk、sci-fi-hud、soft-3d、y2k、retro-computer 的正文灰字均处于"能读但不舒服"区间，可统一上调一档；
- **首屏中景断带**：neo-brutalism（200px）、cyberpunk（240px 黑带）、y2k（210px 星空）、neumorphism（300px 死灰）都存在英雄区与第一内容区之间的空档，除 neumorphism 外多可归为氛围留白，但节奏阈值需要统一意识；
- **画廊页的风格表达力为零**：20 张卡片同构同色（白底 + 灰边 + 黄色"部分页面"徽章），没有为每种风格注入任何视觉签名（registry 中 `preview` 字段也全部为空），"卖风格"的页面自己最朴素；
- **移动端单列降级整体合格**：各风格签名元素（贴纸、玻璃、瓦片、窗口、皮革、像素面板）在移动图上均保留，metro 保持双列瓦片、dashboard KPI 变双列，未出现"移动端即风格消失"的情况。

## 四、Top 10 改进清单（全站视角，按性价比排序）

1. **修复 Y2K 首屏 CTA 隐形**（P1）：两枚按钮恢复 Y2K 材质语法——铬/气泡渐变面 + 高光 + 白描边，与背景明度差 ≥ 3:1；这是唯一的"气质 + 可用性"双杀级缺陷。
2. **消除 Neumorphism 首屏死灰区**（P1）：压缩空档 50%，空出的位置放一组凸起/内凹构件（表盘、推子、开关），既填补构图又给新拟态补上缺席的"物件签名"。
3. **为 Liquid-Glass 制造"可折射物"**（P1）：在玻璃板层后布置彩色光斑/渐变球体，让 blur 真正工作，并给板缘加亮边高光；把材质从"深色半透明卡"拉回"液态玻璃"。
4. **治理"精选项目空腔"**（P2，三个风格）：cyberpunk / sci-fi-hud / flat-design 统一改版式——卡片占 55%-60% 宽，右侧以该风格语言补参数表/日志/几何色块（如 sci-fi-hud 的键值读出表、cyberpunk 的系统日志块）。
5. **画廊页注入风格视觉签名**（P2）：为每张卡加一条该风格的"签名条"（4-6px 色带或角标纹理：pixel 点阵、瑞士红块、皮革棕、霓虹青……），配合 registry 已预留的 `preview` 字位；让画廊自己变成第 21 个风格展示位。
6. **Minimalism 断词修复**（P2）：技能行英文词组 `word-break: keep-all`，消除 "EC/harts" 断裂——一处 CSS 修复整个风格的排版专业度。
7. **Editorial 孤字治理**（P2）：副标题加 `text-wrap: balance`（或调 max-width），消掉"者"字孤行；顺带校准目录与首节的气口宽度。
8. **暗色系正文对比度统提一档**（P2）：cyberpunk / sci-fi-hud / soft-3d / y2k / retro-computer 的描述文字统一上调（目标观感对比 ≥ 4.5:1），一次性解决五个风格的共同短板。
9. **Web 2.0 标题层级回归**（P2）："关于我"等区块大标题从浅灰蓝改为实色蓝并加字重，副文案加深两档；防止装饰色吞掉信息层级。
10. **Terminal 黑场 motd 化**（P2/P3）：光标下加 ASCII art 站名横幅 + neofetch 式系统信息块（博客/项目计数），保留命令交互纯度的同时给首次到访者一个"可看"的首屏。
