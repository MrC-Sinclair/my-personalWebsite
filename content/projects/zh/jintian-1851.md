## 项目简介

以晚清六十余年（1851–1912）为舞台的文字策略抉择游戏。玩家从文官、武将、商贾、士绅、宗室五类身份中择一开局，选择所属势力，在军事、经济、政治、民心、外交五个维度上运筹，并在太平天国、洋务运动、甲午战争等真实历史事件中做出抉择——每一次选择都会改写国运走向。

与预设文本分支不同，游戏进程由大模型实时生成，玩家的每个决策都会真正改变后续叙事。

## 架构

- **前端**（`game-web/`）：uni-app（Vue 3 + TypeScript），一套代码同时构建 **H5** 与 **微信小程序**
- **后端**（`server/`）：Nuxt 3 纯 API 服务，基于 **Vercel AI SDK** + **Drizzle ORM** + **PostgreSQL（pgvector）**
- **文档**（`docs/`）：设计文档、接口文档、数据库 Schema、AI 成本约束
- **规格**（`openspec/`）：需求与变更规格

## 技术特点

- **多身份开局**：5 类身份各有属性偏移与推荐势力，开局即决定玩法倾向
- **五维 + 四资源体系**：军事、经济、政治、民心、外交相互制衡，配合资源约束构成策略深度
- **AI 驱动叙事**：事件与结果由模型实时生成，而非固定分支，重玩性高
- **向量检索**：pgvector 存储历史背景与上下文，让长线剧情保持连贯
- **双端同构**：uni-app 一套代码覆盖 H5 与小程序，省去两套维护成本
- **AI 成本约束**：专门设计了调用成本约束，避免长线叙事把 token 烧穿

## 实现亮点

1. 前后端分离清晰：Nuxt 3 只做 API，游戏逻辑与呈现层解耦
2. 用 pgvector 做剧情记忆，解决长线叙事前后矛盾的问题
3. uni-app 跨端：同一份 Vue 3 代码编译到 H5 与微信小程序
4. 规格先行：需求与变更写在 `openspec/`，改动有据可查
5. 成本可控：把 AI 调用成本当作架构约束而不是事后优化
