## Overview

A text-based strategy game set across six decades of the late Qing dynasty (1851–1912). You pick one of five identities — civil official, military commander, merchant, gentry or imperial clansman — choose a faction, and steer five dimensions: military, economy, politics, public support and diplomacy. Real historical currents (the Taiping Rebellion, the Self-Strengthening Movement, the First Sino-Japanese War) force decisions that rewrite the nation's fate.

Unlike pre-written branching fiction, the narrative is generated by a model in real time, so each decision genuinely changes what happens next.

## Architecture

- **Frontend** (`game-web/`): uni-app (Vue 3 + TypeScript) — one codebase builds both **H5** and the **WeChat Mini Program**
- **Backend** (`server/`): Nuxt 3 as a pure API service, built on **Vercel AI SDK** + **Drizzle ORM** + **PostgreSQL (pgvector)**
- **Docs** (`docs/`): design docs, API docs, database schema, AI cost constraints
- **Specs** (`openspec/`): requirements and change specs

## Highlights

- **Five starting identities**, each with its own attribute offsets and recommended faction
- **Five dimensions + four resources** that constrain each other and create strategic depth
- **AI-driven narrative**: events and outcomes are generated live instead of read from fixed branches, which keeps replays fresh
- **Vector memory**: pgvector stores historical context so long-running storylines stay consistent
- **One codebase, two targets**: uni-app compiles the same Vue 3 code to H5 and the WeChat Mini Program
- **Cost as a constraint**: AI call budgets are designed in from the start rather than optimised later

## Engineering notes

1. Clean split: Nuxt 3 serves only the API, keeping game logic decoupled from presentation
2. pgvector-backed story memory solves the "the plot contradicts itself later" problem
3. uni-app cross-target build: one Vue 3 codebase, two platforms
4. Spec-first: requirements and changes live in `openspec/`, so every change is traceable
5. AI cost treated as an architectural constraint, not an afterthought
